# AskMe! クライアント - Windows版

VRChatのワールド移動をもっと便利にする、Windows専用のデスクトップアプリです。

## ✨ AskMe! とは？

AskMe! は、VRChatをプレイしているあなたのワールド移動をスムーズにするためのツールです。VRChatのログファイルを自動で監視し、あなたが「どのワールドのどのインスタンスにいるか」をリアルタイムで検知します。

検知した情報から、VRChatの公式ランチURLを自動で生成してくれるので、そのURLをクリックするだけで、いつでも・どこからでも同じワールドの同じインスタンスに簡単に入り直すことができます。フレンドと合流したい時や、特定のインスタンスに再入場したい時にとても便利です。

## 🚀 主な機能

- **自動ワールド検知**: VRChatでワールドを移動すると、今いるワールド名とインスタンスIDを自動で検出します。
- **ワンクリックで再入場**: 検出されたワールドのランチURLを生成。クリックするだけで、同じインスタンスにすぐ再入場できます。
- **訪問履歴**: 過去に訪れたワールドの履歴を自動で記録します。
- **シンプルな画面**: 難しい設定は不要。直感的な操作で利用できます。

## 📥 インストール方法

### そのまま実行する場合 (推奨)

1. リリースページから最新の `askMeWindows.zip` をダウンロードし、任意の場所に解凍します。
2. 解凍したフォルダ内の `askMeWindows.exe` をダブルクリックして起動します。
   （WindowsのSmartScreen警告が表示された場合は、「詳細情報」をクリックし、「実行」を選択してください。）

### 自分でビルドする場合

開発者向け:
Visual Studio 2022 または .NET 8.0 SDK が必要です。

1. このプロジェクトのファイルをダウンロードします。
2. コマンドプロンプトやPowerShellを開き、ダウンロードしたフォルダに移動します。
3. 以下のコマンドを実行してビルド、起動します。
   ```bash
   dotnet build -c Release
   dotnet run
   ```
   または、Visual Studioで `askMeWindows.sln` を開いてビルド・実行することもできます。

## 📝 使い方

1. **AskMe! を起動します**
   - ダウンロードした `askMeWindows.exe` をダブルクリックするか、インストール後にスタートメニューから起動します。

2. **VRChatを起動して遊び始めます**
   - いつも通りVRChatを起動し、ワールドを移動してみましょう。

3. **ワールド情報を確認**
   - AskMe! の画面にある「現在の場所」パネルに、あなたが今いるワールドの名前とインスタンスIDが表示されます。
   - 表示された「Launch URL」をコピーしてフレンドに教えたり、隣の「開く」ボタンをクリックしてブラウザから直接ワールドに入場したりできます。

4. **履歴を確認 (オプション)**
   - 「検出履歴」パネルでは、あなたが過去に訪れたワールドのリストを見ることができます。

## ⚙️ よくある質問・困った時は

- **「ログファイルが見つかりません」と表示される**
  - VRChatが起動しているか確認してください。
  - ワールドに移動するとログファイルが生成されますので、少し待ってみてください。

- **URLが正しく生成されない**
  - VRChatのアップデートによってログの形式が変わることがあります。その場合は、AskMe! のアップデートをお待ちいただくか、開発者にご連絡ください。

- **アプリの動作が重い、応答しない**
  - 設定で「ポーリング間隔」（ログをチェックする頻度）を少し長くしてみてください（例: 1秒 → 2秒）。
